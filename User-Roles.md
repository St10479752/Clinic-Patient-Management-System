# User Roles

## Receptionist

The receptionist manages patient registration and appointment administration.

Responsibilities:
- Register patients.
- Search for patient records.
- Update patient information.
- Delete patient records when required.
- Schedule appointments.
- Cancel appointments.
- View available appointment slots.

## Doctor

The doctor uses patient and appointment information to support patient care.

Responsibilities:
- View patient information.
- View scheduled appointments.
- Check patient records.
- Access information required for consultations.
