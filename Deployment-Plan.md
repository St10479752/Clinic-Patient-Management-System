# Deployment Plan

## Repository

The project source code and documentation are stored in GitHub.

## Version Control

Git is used to track changes made during development. Meaningful commits are used to maintain a clear project history.

## Validation

GitHub Actions automatically validates the repository when changes are pushed.

## Testing

The system should be tested before deployment to confirm that the required functions work correctly.

## Documentation

The ERD, Endpoint Plan and SQL Script are stored in the `/docs` folder for easy access.
