# Project Requirements

## Functional Requirements

1. The system must allow staff to register patients.
2. The system must allow staff to search for patient records.
3. The system must allow staff to update patient information.
4. The system must allow staff to delete patient records.
5. The system must allow staff to display patient records.
6. The system must allow appointments to be scheduled.
7. The system must prevent double-booking of appointment slots.
8. The system must display available and booked appointment slots.
9. The system must generate basic patient and appointment reports.

## Non-Functional Requirements

1. The system should be easy for clinic staff to use.
2. Patient information should be stored securely.
3. The system should provide reliable and accurate information.
4. The system should respond quickly to user requests.
