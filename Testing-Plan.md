# Testing Plan

## Patient Management Testing

- Test registering a new patient.
- Test searching for an existing patient.
- Test updating patient information.
- Test deleting a patient.
- Test displaying patient records.

## Appointment Testing

- Test scheduling an appointment.
- Test cancelling an appointment.
- Test displaying available appointment slots.
- Test preventing two patients from using the same appointment slot.

## Validation Testing

- Test required fields.
- Test invalid patient information.
- Test invalid appointment information.
- Confirm that appropriate error messages are displayed.

## Database Testing

- Confirm that records are inserted correctly.
- Confirm that records can be retrieved correctly.
- Confirm that updated records are stored correctly.
- Confirm that deleted records are removed correctly.
