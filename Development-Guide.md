# Development Guide

## Development Process

The project is developed in stages, beginning with planning and database design, followed by implementation, testing and validation.

## Documentation

Project planning documents are stored in the `/docs` folder.

## Version Control

GitHub is used to manage project versions. Changes should be committed with clear and meaningful commit messages.

## Validation

GitHub Actions is used to automatically validate the repository after changes are pushed.

## Testing

New functionality should be tested before being considered complete. Testing should confirm that the system performs the required operations correctly.
